# Northwind · Пользовательский столбец и справочник дат

[Скачать PBIX с продолжением](northwind-sales-etl.pbix) · [Основной кейс](../README.md)

Продолжение проекта Northwind в Power Query. Отдельный файл сохранён, чтобы показать этап подготовки данных без подмены исходного отчёта.

## Выполненные преобразования

1. В Orders создан столбец Sales с выражением `[UnitPrice] * [Quantity]` и числовым типом.
2. Географические поля приведены к названиям Country и City; изменён порядок столбцов.
3. OrderDate преобразован из «Дата и время» в «Дата».
4. На основе копии Orders создан запрос GuideDate: сохранён OrderDate, удалены повторяющиеся даты.
5. Выделены название месяца и год, затем объединены в Month_Year с разделителем «пробел».

Итог: **2 155 товарных позиций** в Orders, **480 уникальных дат** и **23 значения Month_Year** в GuideDate.

## Что важно в модели

Sales — стоимость позиции до скидок. Она не является прибылью и не учитывает себестоимость.

GuideDate содержит только дни с заказами. Это справочник наблюдаемых дат, а не непрерывный календарь. Создание запроса само по себе не подтверждает настройку активной связи с Orders. Month_Year — текстовая подпись; для графика потребуется отдельный ключ хронологической сортировки.

Основное назначение этого файла — демонстрация преобразований Power Query. Основной отчёт и его PDF находятся в родительском каталоге.
