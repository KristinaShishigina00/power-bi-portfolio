| Каталог | Исходная работа | Материалы в репозитории |
| --- | --- | --- |
| 01-northwind | Лабораторная работа 3, работа с OData Northwind | Исходный PBIX и предоставленный PDF дашборда |

Файлам PBIX даны понятные имена; их содержимое не изменено. PNG-превью получены рендерингом PDF, а не генерацией новых диаграмм. Описания кейсов подготовлены по отчётам, статическим экспортам и структуре PBIX; ограничения интерпретации указаны рядом с результатами.

## Источники данных

- Northwind: [учебный сервис OData](https://services.odata.org/V3/Northwind/Northwind.svc/).
- Financials: учебный набор из листа Excel financials, использованный в лабораторной работе. Исходная книга отдельно не приложена.
- E-commerce: рейтинг Data Insight из исходной учебной работы. Точный URL подключения следует смотреть в Power Query внутри PBIX; он не был восстановлен из текстового отчёта.

Материалы предоставлены как учебное портфолио. Лицензия на сторонние наборы данных этим репозиторием не изменяется.
